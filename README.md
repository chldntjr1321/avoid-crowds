# 내향인 지도 (avoid-crowds)

**사람 적은 곳만 골라 가는 서울.** 집이 최고지만, 나가야 한다면.

서울시 실시간 인구데이터로 지금 덜 붐비는 자치구와 장소를 한눈에 보여 주는 웹 서비스입니다.
서울 전체 지도에서 자치구를 고르고, 그 안의 장소를 골라 앞으로 12시간의 혼잡도 예측까지 볼 수 있습니다.

## 주요 기능

- **서울 전체**: 25개 자치구를 혼잡도(여유 · 보통 · 약간 붐빔 · 붐빔) 색으로 표시합니다. 자치구 색은 그 안 장소 혼잡도의 평균입니다.
- **자치구 확대**: 자치구를 누르면 지도가 그 자치구로 확대되고, 자치구 안의 장소를 혼잡도 색으로 보여 줍니다. 패널에는 붐비는 순서로 장소 목록이 나옵니다.
- **장소 상세**: 현재 혼잡도와 인구, 서울시 안내 문구, 12시간 예측 그래프를 보여 줍니다. 예측에서 혼잡도가 2시간 이상 바뀌는 첫 시각을 "23시에 한산해요"처럼 한 문장으로 알려 줍니다.
- **주소로 화면 상태 관리**: `?gu=중구&place=POI091`처럼 주소가 화면을 정해서, 새로고침하거나 링크를 공유해도 같은 화면이 나옵니다. 브라우저 뒤로 가기로 한 단계씩 돌아갑니다.

## 기술 스택

| 항목          | 사용                                                                      |
| ------------- | ------------------------------------------------------------------------- |
| 프레임워크    | Next.js 16 (App Router, Cache Components)                                 |
| 언어          | TypeScript                                                                |
| 스타일        | Tailwind CSS v4, shadcn/ui                                                |
| 서버 데이터   | TanStack Query (5분마다 다시 불러오기)                                    |
| 차트          | Recharts                                                                  |
| 지도          | SVG (빌드 스크립트에서 d3-geo, mapshaper로 경계 데이터를 SVG path로 변환) |
| 패키지 매니저 | pnpm                                                                      |

서울시 API는 Route Handler(`/api/places`)에서만 호출합니다. 121곳을 한 번에 모아 5분 동안 캐싱하고, 인증키는 서버 환경변수에만 둡니다.

## 실행 방법

### 1. 서울시 API 인증키 발급

[서울 열린데이터광장](https://data.seoul.go.kr)에서 회원가입 후 인증키를 발급받습니다.
이 프로젝트는 [서울시 실시간 인구데이터 (OA-21778)](https://data.seoul.go.kr/dataList/OA-21778/S/1/datasetView.do)를 사용합니다.

### 2. 환경변수 설정

프로젝트 루트에 `.env.local` 파일을 만들고 발급받은 키를 넣습니다.

```
SEOUL_API_KEY=발급받은_인증키
```

`NEXT_PUBLIC_` 접두사를 붙이지 마세요. 붙이면 키가 브라우저 코드에 포함됩니다.

### 3. 설치와 실행

```bash
pnpm install
pnpm dev
```

[http://localhost:3000](http://localhost:3000)에서 확인할 수 있습니다.

`pnpm build`는 빌드 중에도 서울시 API를 호출하므로 `SEOUL_API_KEY`가 필요합니다. Vercel에 배포할 때도 프로젝트 설정의 Environment Variables에 같은 이름으로 넣어야 합니다.

## 지도 데이터 다시 만들기

지도에 쓰는 SVG path는 `src/data/generated/`에 미리 만들어 커밋해 두었습니다. 경계 데이터를 바꿀 때만 아래 과정이 필요합니다.

1. 행정동 경계 파일(약 34MB, 커밋하지 않음)을 `data/raw/`에 받습니다.

   ```bash
   curl -L -o data/raw/HangJeongDong_ver20261001.geojson \
     https://raw.githubusercontent.com/vuski/admdongkor/master/ver20261001/HangJeongDong_ver20261001.geojson
   ```

2. 변환 스크립트를 실행합니다. Node.js 22.18 이상이 필요합니다.

   ```bash
   pnpm build:map
   ```

원본 데이터 설명은 [`data/raw/README.md`](data/raw/README.md)에 있습니다.

## 한계

- 서울시가 제공하는 **주요 121장소**만 볼 수 있습니다. 그중 서울대공원은 과천시에 있어서 자치구 없이 따로 표시합니다.
- 예측은 **12시간까지**만 있어서, 며칠 뒤 계획보다는 "오늘 어디로 갈지" 정하는 용도입니다.
- 데이터 기준 시각은 실제보다 약 30분 늦습니다. 화면에 "2026-11-09 18:40 기준"처럼 기준 시각을 함께 보여 줍니다.
- 서울시의 예측 인구와 예측 혼잡도는 따로 계산되어, 인구가 줄어드는데 혼잡도는 올라가는 경우가 있습니다.
