# 01. 프로젝트 개요

## 한 줄 컨셉

**내향인 지도: 사람 적은 곳만 골라 가는 서울.**
나들이 전에 "지금 덜 붐비는 동네와 장소"를 한눈에 보고 고르는 웹 서비스.

- 부제 아이디어: "집이 최고지만, 나가야 한다면"
- 저장소: https://github.com/chldntjr1321/avoid-crowds

## 누구를 위한 서비스인가

핼러윈, 크리스마스처럼 인파가 몰리는 날 붐비는 곳을 피하고 싶은 서울 시민.

## 왜 만드나

- 주요 날짜마다 서울의 특정 동네에 인파가 몰린다. 그날 어디가 덜 붐비는지 보고 피해 가기 위해서.
- 공간 데이터(경계 파일 → SVG)와 실시간 공공 API(JSON) 핸들링 경험이 목표.

## 마감

- **MVP: 2026-11-08** 배포
- **지원 마감: 2026-11-30**. 11/9~29는 성능·접근성 측정과 개선 (`07-schedule-and-measurement.md`)

## 범위

- **서울만.** 같은 수준의 무료 실시간 API가 다른 지역에는 없다.
- **서울시 주요 121장소만.** 실시간 인구데이터가 이 장소들에만 있다. 그중 서울대공원은 과천시에 있어서 "과천시"로 따로 표시한다. 장소 목록은 코드에 하드코딩하지 않고 파일에서 읽어, 장소가 늘어나도 대응할 수 있게 한다.

## 한계

- API 예측은 **12시간까지**만 있다 (예: 14시에 보면 다음 날 02시까지). 그래서 며칠 전 계획용이 아니라 **"오늘 어디로 갈지"** 정하는 용도다.
- 데이터는 5분마다 갱신되지만 실제 측정 시각과 약 30분 차이가 있다 (14:37 조회 → 14:05 기준). 화면에 "14:05 기준"처럼 기준 시각을 꼭 보여준다.
