## 측정 계획

이력서에 숫자로 쓰려면 **개선하기 전 숫자를 먼저 재 두는 것**이 핵심이다. MVP 배포 날 잰 값이 "전", 개선 후 값이 "후".

| 무엇을                  | 어떻게 재나                                                                                                                                                                              | 전 → 후                                                                                                                                 | 이력서 연결                                    |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| API 응답 크기           | Network 탭 (완료)                                                                                                                                                                        | 도시데이터 174 kB → 인구데이터 2.4 kB                                                                                                   | 필요한 데이터만 고른 API 설계                  |
| BFF 가공 전후 응답 크기 | 같은 시각에 서울시 원본 121곳 응답 크기 합계(curl, places.json의 code로 반복)와 배포된 `/api/places` 응답 크기(curl `%{size_download}`), 둘 다 압축 없이 | 248,587 B → 136,903 B, 45% 감소 (11/10, 121곳 전부, 배포 환경) | 응답 경량화 (화면에 필요한 필드만 서버에서 추림) |
