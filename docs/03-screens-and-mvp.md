# 03. 화면 흐름과 MVP 기능 (2026-11-01 최종)

도안은 `docs/design/`에 있다. 화면을 만들기 전에 해당 PNG를 먼저 보고, 정확한 값은 같은 이름의 HTML에서 읽는다. 색 이름은 `docs/design/tokens.md`.
원본 와이어프레임: https://claude.ai/artifact/Pg9n5sVm2XwXPgrwxER62R

MVP 목표: **"서울 전체에서 한산한 구를 고르고, 그 안의 장소와 12시간 예측까지 보는 것."**

## 1. 화면 흐름 한눈에

카카오 지도 없이 SVG 그림 하나 안에서 파고든다. 모든 단계는 인구데이터 API 하나로 채운다.

```
서울 전체 ──구 클릭──▶ 구 확대 (?gu=중구) ──장소 클릭──▶ 장소 상세 (?gu=중구&place=POI091)
```

- 주소(쿼리스트링)가 화면 상태를 정한다. 새로고침하거나 링크를 공유해도 같은 화면이 나온다.
- **구 확대·장소 상세로 들어갈 때 `router.push`** 로 브라우저 기록을 쌓는다(웹·모바일 같음). 브라우저/폰의 뒤로가기는 한 단계씩 위로 간다.
- 화면 폭 **1024px 이상은 웹 규칙, 미만은 모바일 규칙**(`max-width: 1023px`).

## 2. 시각 스타일

- **입체 지도**: 실제 서울 구 경계를 비스듬히 눕혀(아이소메트릭) 그린다. `transform="scale(1,0.62) rotate(-12 …)"`, 두께는 CSS `filter: drop-shadow(0 3px 0 색)`를 겹쳐 옆면처럼.
- **그림체**: [cs.yeolyi.com](https://cs.yeolyi.com) 메인 일러스트 같은 기술 도면풍. 바탕 `--background`, 서울 아래 은은한 원형 그림자만.
- 서울 밖(경기·인천)은 색 없이 옅게(`--map-outside`, 선 `--map-outside-line`) 그리고 가장자리로 갈수록 바탕색으로 사라진다(radialGradient).
- **한강**: 강북 구(마포·용산·성동·광진)와 강남 구가 맞닿는 경계선을 뽑아 굵은 연파랑 선(`--map-river`, 테두리 blue-300)으로 그린다.
- 혼잡도 색 4단계 + 데이터 없음: `--congestion-free / normal / busyish / busy / none`. hover·선택은 같은 계열의 `-hover` 면 + `-stroke` 테두리(검정 테두리 쓰지 않음).
- 글꼴은 **Pretendard 하나**. 시각·배율 숫자는 `tabular-nums`.
- 색은 반드시 semantic 토큰으로(`tokens.md`). 도안 HTML의 hex를 그대로 복사하지 않는다.

## 3. 웹 (1024px 이상)

### 공통 틀 (도안 `web/01-seoul`)

- **헤더 줄 없음.** 지도가 화면 전체를 채운다.
- 왼쪽 위: 제목 "내향인 지도"(22px 800) + 부제 "집이 최고지만, 나가야 한다면" + "14:05 기준 · 5분마다 갱신".
- 왼쪽 아래: 범례 칩(여유·보통·약간 붐빔·붐빔·데이터 없음).
- 오른쪽: **떠 있는 패널** — 오른쪽 20px, 위·아래 20px, 폭 340, 안쪽 20, 모서리 6px, 패널 그림자. 내용이 길면 패널 안에서만 스크롤.

### 1. 서울 전체 (`web/01-seoul`)

- 25개 구를 혼잡도 색으로. 구 대표값 = 구 안 장소 단계의 평균(여유 1 ~ 붐빔 4, 반올림). 서울대공원(과천)은 평균에서 뺀다.
- 패널: **지금 가장 붐비는 곳 TOP 5**(단계 높은 순, 같으면 인구 많은 순). TOP 5 항목을 눌렀을 때 동작은 MVP에서 정하지 않았다(필요하면 장소 상세로 보내는 쪽으로).
- **hover는 지도에서만 강조**, 패널은 바뀌지 않는다. 구를 **클릭했을 때만** 패널이 바뀐다.
  - hover한 구: 1px만 위로(`translateY(-1px)`, `220ms cubic-bezier(.2,.8,.2,1)`), 이름 진하게, 아래 1.5px 옅은 그림자선. 두꺼운 옆면을 새로 그리지 않는다(이웃 구 이름을 가려서).
  - 나머지 구: 지도 위에 배경색 막(opacity .6)을 덮고 hover 구만 그 위에 그린다(투명 hover 레이어, 구현은 `web/01-seoul.html`의 `hover-layer` 참고).
  - 가장자리 구는 바깥 옆면도 같이 선명하게(`<mask>`로 이웃 구 위는 숨김).
- 데이터 없는 구(중랑구)는 회색, hover 안 됨.
- 서울대공원은 과천 위치에 다른 구처럼 색칠·hover(라벨 "서울대공원 · 과천"). 장소가 1곳뿐이라 클릭하면 바로 장소 상세.

### 1-L. 로딩 (`web/01-L-loading`)

- 지도는 색 없이 `--map-empty`(실패와 같은 바탕). 패널은 TOP 5 자리에 스켈레톤(반짝임).
- 데이터가 오면 400ms 뒤 모든 구 색이 600ms 동안 스르륵 들어온다. 5분 갱신 때는 흰색으로 돌아가지 않고 **바뀐 구만** `transition: fill`로 바뀐다.

### 1-E. 전체 실패 (`web/01-E-error`)

- 지도는 색 없이 모양만, hover 막음. 패널 칸 **정중앙**에 안내 + [다시 시도]. 패널 크기는 TOP 5가 있을 때와 같게 유지.

### 1-S. 일부 실패·오래된 데이터 (`web/01-S-stale`)

- 지도는 마지막 성공 데이터 그대로. 제목 아래에 주황 안내 한 줄(Notice, `role="status"`): "일부 장소를 새로 불러오지 못해 14:05 데이터를 보여주고 있어요."

### 2. 구 확대 (`web/02-district`)

- 구 클릭 → 1번 지도를 viewBox로 그 구까지 확대(0.5초, 움직임 줄이기면 즉시) + 가운데로.
- 확대된 구만 두께 있는 입체 블록: 빈 바탕 `--map-zoom-face`, 옆면 `--map-zoom-wall`, 바닥선 `--map-zoom-edge`. 옆면은 구 path를 아래로 조금씩 옮겨 여러 번 겹쳐 그린다(CSS drop-shadow는 확대하면 1단위보다 작아져 사라짐).
- 나머지 구는 경기도처럼 색·두께 없이(`--map-outside`) 가장자리로 사라진다.
- 그 구에 속한 장소만 혼잡도 색으로 평평하게 칠하고, 구 경계 밖은 `<clipPath>`로 자른다. 다른 구 장소는 그리지 않는다.
- **장소 이름**: 장소의 "보이는 영역"(위에 겹친 작은 장소를 뺀 부분) 안에 들어가는 크기로 자동 맞춤(10px → 7px, 필요하면 두 줄). 7px도 안 들어가면 숨김. hover·선택 시 11px 굵게. 계산은 변환 스크립트에서 장소별로 미리 해 둔다.
- 왼쪽 위: [← 서울 전체] + 브레드크럼 "서울 › 중구" + 안내 "ESC, 빈 곳 클릭, 뿌연 옆 구 클릭으로도 서울 전체로 돌아가요".
- 패널: 구 요약(단계, 장소 수, 단계별 수, 가장 한산한 장소, 기준 시각) + **장소 목록**(정렬 탭 "북적 · 한적", 기본 북적). 목록 줄 hover 바탕 `--muted`. 목록 클릭 = 지도에서 장소 클릭과 같음.

### 2-Z. 휠로 더 확대 (`web/02-Z-wheel-zoom`, MVP 이후 가능)

- **구 확대 뒤에만** 휠·핀치·+/− 로 100~400%. 글자는 화면 크기 고정, 장소별 "이름이 들어가는 최소 배율"을 미리 계산해 그 배율부터 이름 표시. 중구는 300%면 10곳 모두 들어감.
- 5px 넘게 움직이면 드래그(클릭과 구분). 오른쪽 아래 ZoomControls(+/− 세로 묶음, 배율, "서울 {구} 전체 보기"). 배율은 주소에 넣지 않는다. 구현은 d3-zoom.

### 3. 장소 상세 (`web/03-place`)

- 지도에서 그 장소 테두리 `--selected`(진한 회갈색). 테두리는 **장소 ∩ 구 교집합 모양**을 따로 계산해 그린다(clipPath에 잘리지 않게).
- 패널 순서: [← 중구 장소 목록] → 장소 이름 + 단계 → 지금 인구·기준 시각·소속 → **장소 사진(16:9)** → 서울시 안내 문구 → **12시간 예측**.
- 장소 선택 중 다른 장소 클릭 = 바로 전환.

### 3-F. 예측만 실패 (`web/03-F-forecast-error`)

- 예측 그래프 자리(약 214px)를 점선 상자로 두고 정중앙에 안내 + [다시 시도]. 나머지 정보는 그대로.

## 4. 모바일 (1024px 미만)

### 틀 (도안 `mobile/M-flow`)

- 지도가 화면 전체, 정보는 **바텀시트**(shadcn Drawer = vaul, snapPoints).
  - 멈추는 높이 3단: **최소**(손잡이 + 한 줄, 약 76px) / **중간 45%** / **맨 위 = 화면을 덮음**(위 48px만 남기고 뒤 지도에 어두운 막).
  - 지도를 끌거나 핀치하기 **시작하면** 시트가 최소로 내려간다. 자동으로 다시 올라오지 않는다.
  - 구·장소를 탭하면 중간으로. 시트 안은 스크롤.
- 왼쪽 위: 제목 "내향인 지도"(18px) + 한 줄 범례(11px, 4단계). **시각은 헤더에 없고 시트에만**(시트 최소 한 줄에도 표시).
- **+/− 버튼 없음**(핀치). 서울 전체 보기 버튼도 없음(핀치로 1배까지 줄이면 서울 전체).
- **[✕] (시트 오른쪽 위)**: 어느 화면에서든 **바로 처음 화면**(용산 1.8배 + 시트 중간 TOP 5). 한 단계씩 뒤로는 폰의 뒤로가기만.
- `touch-action`으로 더블탭 페이지 확대를 막는다. 누르는 영역은 모두 44px 이상.

### M-1. 처음 화면

- **용산구 가운데 1.8배**로 시작(계산: 25개 구 중 15개는 다 보이고 10개는 가장자리가 잘림, 사라지는 구 없음). 시트 중간에 TOP 5.

### M-2. 구 한 번 탭 = 선택 (기록 안 쌓음)

- 지도가 그 구 가운데로 **2.4배**(0.4초), 서울 색 그대로, 그 구만 떠오르고 나머지는 옅게.
- 시트: 구 이름·단계·"장소 10곳 · 14:05 기준" + [✕], 그 아래 장소 목록(북적 · 한적, 줄 44px).
- 다른 구 탭 = 선택 바뀜. 목록의 장소 탭 = 장소 상세. **이 상태는 브라우저 기록을 쌓지 않는다**(처음 화면에서 뒤로가기 = 사이트를 나감, 괜찮음).

### M-3. 같은 구 다시 탭 = 구 확대 (`router.push`, `?gu=`)

- 웹 2번과 같은 확대 그림. 확대된 구는 **시트 위 남은 공간의 가운데**. 이름이 안 들어가는 장소는 숨김(핀치로 키우면 보임). 시트는 M-2와 같음.

### M-4. 장소 상세 (`router.push`, `?place=`)

- 시트 순서(스크롤): 이름·단계·[✕] → **장소 사진(16:9)** → **지금 인구 카드**(NowCard) → 서울시 안내 문구 → **12시간 예측**.
- 시트 중간 높이에서는 사진·지금 인구까지, 끝까지 올리면(M-4b) 화면을 덮고 예측까지 스크롤로.

### M-5. 시트 최소

- 처음 화면: "지금 가장 붐비는 곳 · TOP 5 · 14:05 기준". 구 선택 중: "중구 · 보통 · 장소 10곳 · 14:05 기준 [✕]".

### 상태 (도안 `mobile/M-states`)

- **M-L 로딩**: 무색 지도 + 시트 중간 TOP 5 스켈레톤, 색 페이드인은 웹과 같음.
- **M-E 전체 실패**: 시트 중간 가운데에 안내 + [다시 시도]. 시트가 최소면 **버튼 없이 "불러오지 못했어요"만 가운데**(다시 시도는 시트를 올려서).
- **M-S 오래된 데이터**: 범례 아래 주황 안내 한 줄, 시트 시각도 주황 글자.
- **M-F 예측만 실패**: 화면을 덮는 시트에서 그래프 자리를 점선 상자 + [다시 시도].

## 5. 공통 부품 결정

- **정렬 탭 "북적 · 한적"** (shadcn ToggleGroup의 `underline` variant): 글자 탭 2개, 고른 쪽만 진한 글자 + 2px 색 밑줄(북적 = red-500, 한적 = green-400). 테두리·바탕·화살표 없음. `aria-pressed` + `aria-label`("북적이는 곳부터 보기" / "한적한 곳부터 보기"). 보이는 높이는 약 30px지만 위아래 투명 여백으로 누르는 영역 44px. 시트 제목 "지금 가장 붐비는 곳"은 그대로.
- **혼잡도 뱃지**: shadcn Badge의 variant(`<Badge variant="busy">붐빔</Badge>`). 별도 파일 없음.
- **장소 사진**: 16:9, 모서리 6px, 아래에 출처·라이선스(11px). 사진은 사용자가 따로 준비. 사진이 없는 장소는 자리째 숨긴다. `next/image` 사용.
- **IconButton**: 아이콘만 있는 버튼은 기본 32×32(모바일 44×44), `aria-label` 필수.
- 부품 목록과 어느 화면에서 쓰는지는 `docs/design/system/DS-3-composites.png` 맨 아래 표.

## 6. 예외 규칙

- **잘못된 주소**: `?gu=`에 없는 구 이름이나 `?place=`에 없는 장소 코드가 오면 에러 화면 없이 조용히 서울 전체를 보여주고 주소에서 잘못된 쿼리를 지운다(`router.replace`, 기록을 새로 쌓지 않음). `?gu=`는 맞고 `?place=`만 틀리면(없는 코드이거나 그 구 소속이 아닌 장소) 그 구 확대 화면까지만.
- **API 실패**: 한 번이라도 성공한 데이터가 있으면 그걸 보여주고 1-S(오래된 데이터) 안내, 한 번도 없으면 1-E(전체 실패).
- **움직임 줄이기**(`prefers-reduced-motion: reduce`): 확대·hover·색 페이드인 모두 즉시.
